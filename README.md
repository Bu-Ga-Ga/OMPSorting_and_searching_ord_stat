# Сортировки и поиск порядковых статистик
Эта программа реализует различные алгоритмы сортировки и методы поиска порядковых статистик (k-й порядковой статистики) в массиве. Программа использует OpenMP для параллельных вычислений.

## Алгоритмы сортировки
1. BubbleSort (Пузырьковая сортировка)
Простейший алгоритм сортировки
2. Сортировка слиянием (Merge Sort)
Реализовано несколько вариантов:
 - Sort1: Рекурсивная реализация
 - Sort1OMP: Параллельная версия с использованием OpenMP sections
 - Sort2: Итеративная реализация (без рекурсии)
 - Sort2OMP: Параллельная версия итеративной реализации с OpenMP for
3. Быстрая сортировка (QuickSort)
Несколько вариантов:
 - QSort1: Базовая реализация с выбором последнего элемента как опорного
 - QSort2: Улучшенная версия с выбором первого элемента как опорного
 - QSort2M: Модифицированная версия с:
     - Рандомизированным выбором опорного элемента
     - Оптимизацией рекурсии ("хвостовая" рекурсия заменена на цикл)
4. Пирамидальная сортировка (HeapSort)
 - Использует структуру данных "куча" (heap)
5. Сортировка подсчетом (CountSort)
 - Требует дополнительной памяти
 - Эффективна для небольших диапазонов значений
6. Поразрядная сортировка (DigitalSort)
 - Сортировка по отдельным цифрам чисел
 - Использует union для доступа к отдельным байтам чисел

## Поиск порядковых статистик
Реализовано три метода поиска k-й порядковой статистики:
1. FindStat1
 - Самый простой метод: сортирует массив и возвращает k-й элемент
 - Использует QSort2M для сортировки
2. FindStat2
 - Использует модифицированный QuickSelect (аналог QuickSort для поиска статистики)
 - Особенности:
       - Рандомизированный выбор опорного элемента
       - Оптимизация рекурсии (замена на цикл)
3. FindStat3
Улучшенный метод с использованием медианы медиан
 - Особенности реализации:
   - Разбивает массив на группы по 5 элементов
   - Находит медиану каждой группы
    - Рекурсивно находит медиану этих медиан
    - Использует эту медиану как опорный элемент


## Особенности реализации
### Параллельные вычисления:
- Использование OpenMP для параллелизации сортировки слиянием
  - #pragma omp parallel sections для рекурсивной версии
  - #pragma omp parallel for для итеративной версии

## Назначение
Программа предназначена для:
 - Сравнения производительности различных алгоритмов сортировки
 - Исследования эффективности параллельных алгоритмов
